Arquitetura do sistema

Fluxo de coleta e inteligência

Esta seção ajuda a vender o projeto para o cliente mostrando que o sistema não para no dashboard: ele nasce preparado para telemetria, rastreabilidade, histórico e evolução preditiva.

1. Sensores

Temperatura, corrente, vibração, tensão, óleo e ambiente.

2. Gateway

ESP32, microcontrolador industrial ou gateway IoT local.

3. Nuvem

MQTT/HTTP, ingestão, banco temporal e engine de alertas.

4. Plataforma

Dashboard web, histórico, ranking de risco e relatórios.

5. Inteligência

Modelos de tendência, previsão e manutenção assistida.
